# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x (pilot) | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities, including a published report that the
re-check does not reproduce, through a
GitHub Security Advisory (GHSA) on this repository:
<https://github.com/OpenSymbolicRules/Verification/security/advisories/new>.

Do not open public issues for security vulnerabilities.
